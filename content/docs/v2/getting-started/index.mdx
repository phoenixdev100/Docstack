Meridian is a platform for building, deploying, and operating integrations between your application and external services. You create a **project**, connect it to your systems through the REST API or an SDK, and Meridian handles execution, retries, event delivery, and observability.

This documentation covers everything you need to build on Meridian - from your first authenticated request to production hardening.

## What you can build

- **Data sync pipelines** - keep external systems in sync with your database using scheduled or event-driven syncs.
- **Webhook infrastructure** - subscribe to events, verify signatures, and handle deliveries with automatic retries.
- **Automated workflows** - chain API calls, transform payloads, and react to state changes without running your own workers.

## A first look

Every interaction with Meridian is an HTTPS call to `https://api.meridian.dev/v2` authenticated with a Bearer token:

```bash title="Terminal"
curl https://api.meridian.dev/v2/projects \
  -H "Authorization: Bearer $MERIDIAN_API_KEY"
```

```json title="Response"
{
  "object": "list",
  "data": [
    {
      "id": "prj_1fK2nV9xQe",
      "name": "billing-sync",
      "region": "us-east",
      "environment": "live",
      "created_at": "2026-08-14T09:31:07Z"
    }
  ],
  "has_more": false,
  "next_cursor": null
}
```
