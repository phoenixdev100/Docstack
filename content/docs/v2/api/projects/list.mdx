<ApiEndpoint method="GET" path="/projects" />

Returns a cursor-paginated list of projects in the environment of the calling key, newest first.

## Parameters

<ParamTable
  label="Query parameters"
  params={[
    { name: "limit", type: "integer", description: "Items per page, 1–100.", default: "25" },
    { name: "cursor", type: "string", description: "Cursor from a previous response's next_cursor." },
    { name: "order", type: "string", description: "asc or desc by created_at.", default: "desc" },
    { name: "status", type: "string", description: "Filter by status: active, suspended, archived." },
    { name: "region", type: "string", description: "Filter by region: us-east, eu-west, ap-south." },
    { name: "created_after", type: "timestamp", description: "Only projects created after this RFC 3339 time." },
    { name: "created_before", type: "timestamp", description: "Only projects created before this time." },
  ]}
/>

## Example request

<CodeTabs>

```bash title="cURL"
curl "https://api.meridian.dev/v2/projects?limit=10&status=active" \
  -H "Authorization: Bearer $MERIDIAN_API_KEY"
```

```javascript title="JavaScript"
// Auto-paginating iterator
for await (const project of client.projects.list({ status: "active" })) {
  console.log(project.id, project.name);
}

// Or fetch a single page
const page = await client.projects.list({ limit: 10, status: "active" });
// page.data, page.hasMore, page.nextCursor
```

```python title="Python"
for project in client.projects.list(status="active"):
    print(project.id, project.name)
```

```go title="Go"
it := client.Projects.List(ctx, &meridian.ProjectListParams{
    Status: meridian.String("active"),
})
for it.Next() {
    p := it.Current()
    fmt.Println(p.ID, p.Name)
}
```

</CodeTabs>

## Errors

| Status | Code | Condition |
| --- | --- | --- |
| `400` | `parameter_invalid` | `limit` outside 1–100, or malformed `cursor` |
| `401` | `invalid_api_key` | Missing/revoked key |
| `403` | `insufficient_scope` | Key lacks `projects:read` |

<Callout type="tip">
  Iterate with the SDK's auto-pagination instead of hand-rolling cursor loops - it handles `has_more`, retries, and `429` pacing for you.
</Callout>
