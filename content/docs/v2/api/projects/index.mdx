Projects are the top-level container for integration work. All other resources - webhook endpoints, events, environments - belong to a project.

## The project object

```json title="project" {2}
{
  "id": "prj_9kLm2xVb7nQe",
  "object": "project",
  "name": "billing-sync",
  "region": "us-east",
  "environment": "test",
  "status": "active",
  "created_at": "2026-08-14T09:31:07Z",
  "updated_at": "2026-09-02T14:12:44Z"
}
```

## Events

Mutations emit events you can subscribe to via [webhooks](/docs/api/webhooks):

| Type | Fired when |
| --- | --- |
| `project.created` | A project is created |
| `project.updated` | `name` or `status` changes - includes `previous_attributes` |
| `project.archived` | A project is soft-deleted |
| `project.restored` | An archived project is restored |

  Looking for member management? Project membership inherits workspace roles - see [Users](/docs/api/users) and [Permissions](/docs/concepts/permissions).
