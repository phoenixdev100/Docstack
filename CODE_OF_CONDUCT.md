# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

In short: be respectful and constructive. Harassment, personal attacks, and exclusionary behavior are not tolerated. Maintainers may remove or reject contributions and ban participants who violate these standards.

Report unacceptable behavior by opening a private security advisory or contacting the maintainer listed in the repository profile. All reports are handled confidentially.
